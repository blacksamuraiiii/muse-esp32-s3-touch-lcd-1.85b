## 写文档的约定

- 日期用 `YYYYMMDD` 前缀，待办与进展成对出现：`20261018待办.md` → `20261018-进展记录.md`。
- 进展记录只写**做完了什么、证据是什么、还差什么**；踩过的坑一律进 `踩坑记录.md`。
- 结论必须带证据：串口日志原文、实测数字、命令输出。没有证据的写"待验证"。
