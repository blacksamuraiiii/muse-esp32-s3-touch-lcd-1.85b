# 数独删除说明（2026-11-20，固件包保守压缩批）

数独（6×6，2026-10-31 上线）2026-11-08 已归档（360px 圆屏看不清 6×6
棋盘、点按不方便），2026-11-20 在固件包保守压缩批里把代码从树里删掉，
省约 8–12 KB flash（实测见下）。

## 刻意没删的：宠物账本

`muse_pet_model.c/h` 里的 `sudoku_day` / `sudoku_entry_paid` /
`sudoku_reward_coins`、`PET_SUDOKU_ENTRY` / `PET_SUDOKU_SOLVE`、
`muse_pet_sudoku_today()`、`muse_input.c` 里的 `pet.sudoku` 台架命令、
`tests/pet_economy_harness.c` 里的数独用例——**全都没动**。账本是 NVS
持久状态的一部分，删字段会破坏已烧录设备的状态迁移；留着它，恢复的
数独页接上就能用（入场 5 / 首解 +10 的口径不变）。

## 恢复办法

最后一份带数独代码的提交是 main `59f7d3b`（1.5.4b）。从 git 历史取回
四个文件：

```sh
git show 59f7d3b:esp32/components/muse/muse_sudoku.c > \
    esp32/components/muse/muse_sudoku.c
git show 59f7d3b:esp32/components/muse/muse_sudoku_ui.c > \
    esp32/components/muse/muse_sudoku_ui.c
git show 59f7d3b:esp32/components/muse/muse_sudoku.h > \
    esp32/components/muse/muse_sudoku.h
git show 59f7d3b:esp32/components/muse/muse_sudoku_ui.h > \
    esp32/components/muse/muse_sudoku_ui.h
```

然后按 `muse_interact_ui.c` 里 `build_minigame` 上的恢复注释接回去：
CMakeLists 两条、`IC_PAGE_SUDOKU` 页（hide 列表、show 映射、
`on_back()` / `on_hidden()` 的 hide 钩子）、`build_minigame` 里的
`minigame_card()` 调用（排在它原来的位置）、`on_open_sudoku`、
`refresh_status()` 里的 `s_mg_sudoku_lbl` 变灰行（加
`sudoku_paid` 查找）、文件顶部的 `*s_mg_sudoku_lbl` 标签声明。
host 测试也一并取回：`tests/test_sudoku_logic.py` 与
`tests/sudoku_logic_harness.c`（同提交同路径）。

## 实测省量

删文件省的是源码行数，flash 省量须用户编译确认（本机无工具链）：
四个源文件约 1,277 行（含 20 道题库与 6×6 棋盘 UI），审计估算
8–12 KB。host 测试套件从 644 变为 643 个用例（删了 1 个
test_sudoku_logic 用例），其余失败数不变（见压缩批汇报）。
