# 新版 CJK 字库（muse_font_cjk_noto_16）再生说明

- 日期：2026-11-20。背景：固件包保守压缩批（分支 `feat/size-trim-conservative-20261120`）重生成了 CJK 字库，但新文件 5.5 MB，GitHub push-files 接口报 413 推不上去。**不要再试推这个文件**——按本文档在本地重新生成，再用本地 git 推。
- 输出文件：`esp32/components/muse/fonts/muse_font_cjk_noto_16.c`，约 5,518,591 B；字形数 7,242；`glyph_bitmap` 721,254 项。
- 最准的再生方法：直接跑分支上已有的脚本 `esp32/tools/muse/gen_cjk_noto_font.sh`（已推上远端，头 `2c214d8`）。本文档是脚本做的事的逐项说明，供另一个智能体核对与复现。

## 1. 源字体与工具

- 源字体：Noto Sans SC Medium，OFL 授权。下载地址（脚本里就是这个）：
  `https://github.com/notofonts/noto-cjk/raw/main/Sans/SubsetOTF/SC/NotoSansSC-Medium.otf`
- 生成工具：**lv_font_conv@1.5.3**（`npx -y lv_font_conv@1.5.3`）。注意：**不是 1.5.2**——1.5.2 不支持 `--lv-font-name`，原文件 Opts 行含该参数，只能是 1.5.3 生成的。审计报告里写的 1.5.2 是错的，已纠正。
- 参数：`--size 16 --bpp 4 --format lvgl --lv-font-name muse_font_cjk_noto_16`。

## 2. 新版包含哪些字（7,242 个字形）

| 范围 | 内容 | 说明 |
|---|---|---|
| 0x20–0x7E | ASCII（95 字） | 不变 |
| 0xA0–0xFF | Latin-1（96 字） | 不变 |
| 0x3000–0x303F | CJK 标点（64 码位） | **保留**：、。〈〉《》等都在这段 |
| 0xFF00–0xFFEF | 全角形（240 码位） | 不变 |
| GB2312 全部汉字 | 6,763 字 | 脚本用 Python 从 GB2312 编码表扫出（`0xB0–0xF7` × `0xA1–0xFE` 解码），不要手写清单 |
| 0x7B4A | 筊 | 单独加：掷筊页的字，GBK 才有、GB2312 扫不到（2026-11-16 曾因此渲染空白） |

## 3. 新版删除了哪些东西

相对旧版（main `59f7d3b`，6,440,909 B，7,431 字形），一共三项，**一次生成里同时做**，不要分三次生成：

### ① 假名：删 189 个字形

- 旧版范围 `0x3000–0x30FF` → 新版 `0x3000–0x303F`。删的是假名段，标点段保留。
- 平假名：U+3041–U+3096、U+3099–U+309F，共 93 个。
- 片假名：U+30A0–U+30FF，共 96 个。
- 合计 189 个。注意：U+3040、U+3097、U+3098 在源字体里本来就没有字形（已用 fontTools 对源 OTF 核对过），所以 192 个码位只对应 189 个字形。
- 风险：界面与 LLM 中文回复基本不出现假名；如果哪天回复里出现假名，那个字会显示豆腐（空白方块）。

### ② 拉丁 kerning：删整个 kerning 表

- 生成时加 `--no-kerning`。实测省 20,798 B（ids 数组 + values 数组两部分；审计报告的 16,705 B 只算了 ids，漏了 values，已纠正）。
- 副作用：拉丁字母间距略松，中文界面几乎无感。

### ③ 开压缩：去掉 `--no-compress`

- LVGL 9 原生支持压缩字形，渲染时解压，**不用改任何代码**。
- 位图 875,719 B → 721,254 B，省 154,465 B（约 16%）。

三项合计：host `.o` 对比 970,327 B → 793,430 B，省 **176,897 B**。另有字形描述 −1,512 B（189×8 B）、假名 cmap −122 B，四项加总与 176,897 分毫不差。

## 4. 后处理（脚本里已包含，重新生成时别漏）

1. `#include "lvgl/lvgl.h"` → `#include "lvgl.h"`；去掉临时目录路径。
2. 行高钉死：`.line_height = 20`、`.base_line = 5`。Noto 原生是 31/9，但全部版式都是按 20/5 调过的，不钉会乱版。

## 5. 新旧 Opts 行对照（生成文件头第 4 行，供核对）

旧版：

```
--font noto.otf --size 16 --bpp 4 --format lvgl --lv-font-name muse_font_cjk_noto_16 --no-compress -r 0x20-0x7E -r 0xA0-0xFF -r 0x3000-0x30FF -r 0xFF00-0xFFEF -r <GB2312 汉字表> -r 0x7B4A
```

新版（只改三处，其余不动）：

```
--font noto.otf --size 16 --bpp 4 --format lvgl --lv-font-name muse_font_cjk_noto_16 --no-kerning -r 0x20-0x7E -r 0xA0-0xFF -r 0x3000-0x303F -r 0xFF00-0xFFEF -r <GB2312 汉字表> -r 0x7B4A
```

即：删 `--no-compress`、加 `--no-kerning`、`0x3000-0x30FF` 改成 `0x3000-0x303F`。
