# 毛毛飞行移植说明（2026-11-07）

第六个小游戏：毛毛飞着往上爬，点屏幕扇翅膀、点左/右半边往左/右飞，踩云弹起、吃金币得分，掉出底边结束。显示名“毛毛飞行”（2026-11-07 用户定，原名“涂鸦跳跃”）；小游戏列表里排在金币雨之后（本分支基点是 main、金币雨不在其中，所以本分支里它是第 5 行，合入时排到金币雨之后变第 6 行，见“与金币雨分支的关系”）。效果图 v5（`doodle-mockup-v5.png` / `-start.png`）已由用户拍板。分支 `feat/doodle-20261107`，2026-11-07 已合入 main（合并提交 `cc2a830`）。

## 玩法与经济

- 无尽模式，没有计时：点一下扇一下（起跳 -11 px/tick），重力 0.4 px/tick² 往回拉；云是单向的，只能从上面落上去弹起（弹起 -9 px/tick），从下面穿过去不弹；掉出底边结束。
- 云三色（用户 2026-11-07 定）：白静态、蓝横移（左右滑、碰边回头）、灰易碎（踩一次就碎、立刻在顶部补一朵新的，场地云数不变）；云竖向间隔约 70 px，相机在她升到 y=130 以上时跟随上移，云从底边出去就回顶部。
- **得分只算金币**（用户 2026-11-07 定）：吃一个金币 +1 分，踩云不得分；没有炸弹、没有命，分数只涨不跌。金币是漂浮拾取（一条往上走的轨迹，约 60% 的新云头顶带一枚），碰到就吃（判定框是毛毛半身 + 半个金币， generous，孩子不用飞得像素级准）。
- 物理参数（16Games-in-Cpp Doodle Jump 抄来：重力 0.2、起跳 -10、平台间隔 80px，换算到 50 ms tick）：重力 0.4、扇翅 -11（约 150 px 升幅，两个云距）、弹起 -9（约 100 px，一个半云距）、横移 3 px/tick、左右出界绕回另一边（经典涂鸦跳跃玩法）。
- 经济与蛇/地鼠/金币雨完全相同：开局扣 5（`PET_FEE`，金币 <5 拒绝并提示“金币不够（需 5 枚）”），结束时分数 1:1 兑金币、**上限 10、下限 0**（分数不可能是负数，不用截断，直接调 `muse_pet_round_coins()`），HUD 只写毛兑“本局 n 分，+m 金币”，不写净得。
- 控制：点屏幕起飞（点左半边往左飞、点右半边往右飞，一次点按同时管方向和起飞），长按中间（手指基本不动、0.5 秒）暂停。无顶部暂停钮（2026-11-01 已删，见蛇/地鼠）。毛毛会飞（用户 2026-11-07 定），脚下没有板，实机上她是倾斜飞行的（按横移方向倾 ±9°，无速度线）。

## 与金币雨分支的关系

本分支基点是 main（87b9cfe），金币雨不在 main 里，所以毛毛与金币的美术文件是**从金币雨分支原样复制**过来的（blob SHA 与金币雨分支 `6d0819b` 上的完全一致）。将来两个分支都合进 main 时，这三个文件内容相同、不会冲突；`muse_interact_ui.c` 里小游戏列表与页面枚举两处（都在“打地鼠”之后加行）需要合一次，顺序是金币雨在前、毛毛飞行在后（用户 2026-11-07 定：列表排在金币雨之后）。

## 美术

- 金币：game-icons Delapouite `token.svg`（CC BY 3.0）；**发版说明须注明作者**。
- 毛毛：用户上传的动画原画（与 2026-09-27 头像同款），按 v7 定稿重绘：眼睛原样（白高光/黑/绿/白）、高光放大 5 px、裤子刷白；漫水抠图。
- 云：无素材，UI 里 LVGL 原语画（底座 + 三个圆，白/蓝/灰三色），66×26。
- Flash：金币 1,296 B + 毛毛 13,992 B ≈ 15.3 KB（1.5e 时槽余约 316 KB；1.5 正式版后的 bin 大小以构建实测为准）。

## 验收清单（用户本机）

```sh
cd esp32
tools/muse/board.sh build lcd185b   # 看 check_sizes：app 须 < 4 MB
tools/muse/board.sh flash lcd185b
```

1. 互动 → 小游戏列表出现第 6 行“毛毛飞行”（金币雨之下），可竖滑；点进后标题“毛毛飞行”、开始钮“开始”、提示“点左/右飞翔，长按中间暂停”。
2. 点左半边屏幕 → 她往左上飞；点右半边 → 往右上飞；不点就往下掉；左右出界绕回另一边。
3. 落到白云上弹起；蓝云左右滑；灰云踩一次就碎（碎后顶部立刻补一朵新的）。
4. 吃金币 +1 分；踩云不得分（HUD 只涨金币数）。
5. 飞得越高画面往下滚、新云从顶部进来；掉出底边 → 标题变“游戏结束”，计分行变金“本局 n 分，+m 金币”；“再来一局”钮带“- 5 金币”，点下再扣 5。
6. 金币 <5 时点开始 → 拒绝提示“金币不够（需 5 枚）”，不扣费、不开局。
7. 长按中间区域 0.5 秒 → “已暂停”+“继续”；返回箭头出现，点回小游戏列表；再进应从暂停态恢复（不重新扣费）。点按中拖动不停住 0.5 秒**不应**暂停。
8. 子页面不能右滑到对话页（禁滑），三个点不出现；按 BOOT 回对话页。
9. 算 24、打砖块未做：本分支只有毛毛飞行；算 24、打砖块仍是待定项。
