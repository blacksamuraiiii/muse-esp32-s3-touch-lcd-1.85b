## 约定

- 文件名 `YYYYMMDD-<主题>.md`，一天内同一主题只留一份。
- 说明里的坐标、字号、颜色写**实参**（与代码一致），改了代码就同步改这里。
- 已失效的说明移到 `archive/`，不删除：回溯时需要知道当时为什么那样做。
