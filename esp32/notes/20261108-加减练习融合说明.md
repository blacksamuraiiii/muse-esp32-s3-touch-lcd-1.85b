# 加减练习（融合版）移植说明（2026-11-08）

用户 2026-11-08 晚决定：把「加减练习」和「凑十法练习」融合成**一款**游戏，名字仍叫「加减练习」。本文件取代 `20261108-加减练习移植说明.md` 与 `20261108-凑十练习移植说明.md` 的实现部分（那两份保留为历史）。

## 玩法（用户口径 2026-11-08）

- 两类题型，随机各约一半：
  - **个位数相加（凑十法）**：`a + b ? d`，`a`、`b` 取 2..9，和落在 11..18（一定进位）。
  - **十位数减个位数（借十法）**：`a - b ? d`，被减数 11..18，减数 2..9 且**大于被减数个位**（必须借位），差 2..9。
- 比较数 `d` 是真值或近 miss（差 0 / ±1 / ±2），所以题面 20% 左右是「=」，其余分别需要「>」或「<」——必须真算，不能蒙。
- 下方三个按钮 `>` `<` `=`（琥珀 / 绿 / 蓝，90×64），点一个让等式成立。
- **点完立即提示对错**：绿色「正确，+1 分」／红色「错误，不得分」，设在计分行上方（y=280）；答错时同时把正确的按钮加白边。0.6 秒后出下一题，期间点按无效（防连点跳题）。
- 答对 +1 分，答错不得分（不扣分）；计时 **3 分钟（180 秒）**，用户 2026-11-08 从 30 秒延长；开局扣 5 金币、1 分 = 1 金币，**单局兑付上限随之上调到 20**（`MUSE_PET_ROUND_COIN_MAX_MATHPRACTICE`，其他游戏仍按 `MUSE_PET_ROUND_COIN_MAX` 的 10；worker 用 `MUSE_PET_ROUND_COIN_HARD_MAX` 兜底防 UI 造币）。
- **取消中间的提示算式行**（原凑十法练习的 `10-8=2  5-2=3`），算式与按钮之间只留题面与间距。
