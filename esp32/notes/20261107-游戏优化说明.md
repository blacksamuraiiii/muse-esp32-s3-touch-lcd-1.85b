# 20261107-游戏优化说明

分支 `feat/game-polish-20261107`，基点金币雨分支 `6d0819b`。用户 2026-11-07
拍板的三项游戏视觉优化（以第一稿效果图为准，眼睛优化分支作废）。

## 改动

1. **去掉深紫色背景块**（打地鼠、金币雨）：
   - `muse_whackamole_ui.c`、`muse_goldrain_ui.c`：删掉 240×240 CARD 场
     （`fill(page, MUSE_THEME_CARD)`）。洞/鼠、金币/炸弹/毛毛本来就是
     直接挂在 page 上的绝对坐标，删场只去底色，不动布局与触摸。
     渲染对照：`whackamole-mockup-v11.png`、`goldrain-mockup-v11.png`。
2. **金币雨换第一稿美术**（`goldrain-new-art-v1.png`）：
   - 毛毛：用户 2026-11-07 上传的飞行毛毛（抱麻将“發”）原图，未做
     眼睛优化。`muse_goldrain_sprite.c` 由 53×66 改为 **61×66**
     （牌让精灵更宽），`MUSE_GOLDRAIN_SPRITE_W` 53→61；接取判定与
     左右夹取（`muse_goldrain.c`）走该常量，不用另改。
   - 金币：右下角星星金币，`muse_goldrain_coin.c` 由 Delapouite token
     换成金底黑边四角星，仍 18×18（`MUSE_GOLDRAIN_COIN_PX` 不变）。
   - 生成脚本 `~/workspace/game-polish-art-gen.py`；预览
     `game-polish-sprite-preview.png`、`game-polish-coin-preview.png`。
   - 主机测试：`tests/goldrain_logic_harness.c` 两处硬编码 53.0f 改
     为 `MUSE_GOLDRAIN_SPRITE_W`（夹取断言随常量走）。
3. **毛毛跳跃金币同步换新**：本分支不含毛毛跳跃（基点是金币雨分支），
   星星金币已另推到 `feat/doodle-20261107`（同一份
   `muse_goldrain_coin.c`，见该分支说明）。合入顺序：金币雨在前、
   毛毛跳跃在后；两分支合入时 `muse_goldrain_coin.c` 内容一致，不冲突。

4. **飘字特效（2026-11-07 用户追加）**：金币雨吃到金币时在接取处飘
   金色“+1”，吃到炸弹飘红色“-5”；毛毛跳跃吃到金币飘金色“+1”。
   实现：`on_tick` 里记 tick 前后分数差，差值非 0 即在接取/收集处
   生成一个 label，`lv_anim` 700ms 内上飘 36px 并淡出，完成后自删
   （单动画同时驱动上飘与淡出，`user_data` 存起始 y；金币雨在
   `muse_goldrain_ui.c`，毛毛跳跃在 `muse_doodle_ui.c`）。

## 2026-11-07 追加：毛毛跳跃的 +1 飘字（用户口径）

「毛毛跳跃里面吃到金币也要有 +1 的特效（跟金币雨一样）」。因为要两页同款，
把飘字从 `muse_goldrain_ui.c` 的页内实现提成共享件：

- `muse_widgets.c/h` 新增 `muse_float_text(parent, text, colour, cx, y)`：
  700 ms 上飘 36 px 并淡出，单个 lv_anim 同时驱动位移与透明度，完成回调里
  自删（`a->var`，LVGL 9.5 无 `lv_anim_get_var`）。
- 金币雨改为调用该共享件（原三处 static 函数删除），行为不变。
- `muse_doodle_ui.c` 的 on_tick 记 tick 前后分数差，差值 > 0 时在她上方
  30 px 处飘金色「+1」（金币 +1，本页无炸弹，所以只有正数）。
