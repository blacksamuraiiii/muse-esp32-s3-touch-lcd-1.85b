# Fonts

Since 1.5b there is ONE Chinese face for captions, replies and the
interaction pages, built in only with `CONFIG_MUSE_CJK_FONT`. The shared
chain lives in `muse_font.c` (`muse_font_cjk()` / `muse_font_mont16_cjk()`
/ `muse_font_caption()` / `muse_font_reply()` / `muse_font_btn()`):

- `muse_font_cjk_noto_16.c` — the one CJK face since 2026-11-03: Noto Sans
  SC Medium at 16 px, 4bpp antialiased, taken from upstream's
  `muse_font_cjk_noto_16.c` (upstream's `gen_cjk_noto_font.sh`, GB2312
  6763 hanzi + CJK punctuation, kana and fullwidth forms, 7240 glyphs,
  ~537 KB of bitmap data, ~650 KB of flash all in). It replaces Source Han
  Sans SC Regular level-1 (3755 hanzi) + the Unifont fallback below, and
  saves about 650 KB of flash: the two old faces cost ~1310 KB. The trade
  is coverage, not looks: a hanzi outside GB2312 (a GBK name character
  like 燊堃喆, which Unifont used to draw rough-but-present) now shows a
  tofu box, and a level-2 hanzi (晟淼鑫) renders smooth instead of as a
  1bpp bitmap. Korean was tofu before and stays tofu: neither the old
  Unifont subset nor Noto covers Hangul.
  Noto's own line metrics are 31/9; the file pins `.line_height` to 20
  and `.base_line` to 5, the line box the screen layout was tuned to (the
  same trick `tools/muse/gen_ui_font.sh` used for Source Han, and the
  same reason 1.5c's 18 px face was abandoned: its 34 px line height made
  the caption band 72 px and pushed Muse up into the READY label).
  Re-running upstream's generator must re-apply this pin.
- `muse_font_sym_16.c` — the symbol tail of the chain, cut from DejaVu
  Sans 16 px 4bpp with lv_font_conv@1.5.3 (114 glyphs, ~3.4 KB of bitmap
  data; the generation command is in the file's header comment). Noto
  covers CJK + fullwidth only and Montserrat 16 covers ASCII + the
  private-use LVGL icons, so neither has the Latin-1 symbols, general
  punctuation, degree-C/F, arrows or geometric shapes the UI prints
  (weather 25℃, hints, reply text). Those live here, as the last link of
  the chain. The face is a fallback only, so its own 21/5 line metrics
  never govern a layout.
- Montserrat 16/14/20 and unscii-16/8 come from LVGL itself. Montserrat's
  private-use range is what the LV_SYMBOL_* icons draw with, which is why
  icon labels can keep bare Montserrat while text labels cannot.

Retired, still in the tree but no longer compiled (the push tool cannot
delete files; remove them via the web UI if the tree should shed them):
`muse_font_ui_16.c` (Source Han level-1, regenerated by
`tools/muse/gen_ui_font.sh`) and `muse_font_cjk_16.c` (GNU Unifont
16.0.04 fallback, regenerated by `tools/muse/gen_cjk_font.sh`).
Removed in 1.5b: `muse_font_cjk_20.c` (the old 20 px 1bpp reply face,
two lines of 12 columns) and its generator `tools/muse/gen_cjk_font20.sh`.
Replies now share the 16 px caption chain and page two lines of 16 columns.
