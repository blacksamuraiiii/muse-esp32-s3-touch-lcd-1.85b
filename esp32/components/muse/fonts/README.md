# Fonts

Since 1.5b there is ONE Chinese face for captions, replies and the
interaction pages, plus a 1bpp fallback, both built in only with
`CONFIG_MUSE_CJK_FONT`. The shared chain lives in `muse_font.c`
(`muse_font_cjk()` / `muse_font_caption()` / `muse_font_btn()`):

- `muse_font_ui_16.c` — the main CJK face: Source Han Sans SC Regular at
  16 px, 4bpp antialiased, covering GB2312 level-1 hanzi (3755 characters)
  plus punctuation, kana and fullwidth forms (4430 code points, ~460 KB of
  bitmap data). Regenerated by `tools/muse/gen_ui_font.sh` (NOT by the
  build: run it by hand after changing the set, then commit the .c file).
  The generator pins `.line_height` to 20 and `.base_line` to 5, the line
  box the screen layout was tuned to (1.5c shipped 18 px Source Han once;
  its 34 px line height made the caption band 72 px and pushed Muse up into
  the READY label, so the face is 16 px again). It replaced WenQuanYi Micro
  Hei 16 px, the old 255-character source-literal subset and the 20 px
  Unifont face below.
- `muse_font_cjk_16.c` — the fallback. 16x16 bitmaps from GNU Unifont
  16.0.04, the same cell as unscii-16, for CJK punctuation, kana, every CJK
  Unified Ideograph (U+4E00 to U+9FFF) and the fullwidth forms: about
  850 KB of flash. A character outside the level-1 set (e.g. a level-2
  hanzi) renders here, so it never shows a tofu box, only a less smooth
  glyph. Regenerated by `tools/muse/gen_cjk_font.sh`.

Removed in 1.5b: `muse_font_cjk_20.c` (the old 20 px 1bpp reply face,
two lines of 12 columns) and its generator `tools/muse/gen_cjk_font20.sh`.
Replies now share the 16 px caption chain and page two lines of 16 columns.
